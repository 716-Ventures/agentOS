# Desktop assets

`alpine-wallpaper.png` is the approved original agentOS concept wallpaper from
`outputs/gui-concepts/alpine-wallpaper.png`. It is embedded in the native binary;
no remote image or browser is used at runtime.

`Commissioner.ttf` is the unmodified variable Commissioner font published by
Google Fonts, retrieved from `google/fonts/ofl/commissioner` on 2026-10-12.
Copyright and SIL Open Font License 1.1 are preserved in `Commissioner-OFL.txt`
and the installed native-shell `licenses/Commissioner-OFL.txt`.
The font is embedded and registered privately through Fontconfig for the process.
Application document components retain the pinned 716 UI typography.
