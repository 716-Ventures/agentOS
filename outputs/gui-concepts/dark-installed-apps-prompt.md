# Installed apps concept

Built-in image-generation edit of dark-voice-workspace.png. Illustrative app inventory, not installed software in the VM. Icon treatment remains exploratory.

Use case: ui-mockup. Continue the attached Agent OS dark GUI concept. Input image role: visual design reference and edit target. Preserve its scenic alpine lake dusk wallpaper, charcoal surfaces, welcoming warm-white typography, restrained pale blue interaction accents, calm refined mood, and straight-on full-screen composition. Create a new state answering the user's instruction "Show my installed apps". This is an exploratory future OS mockup; app names are illustrative, not an inventory of the current prototype.

Replace the existing foreground listening panel with a beautifully composed, larger central agentic launcher expanded into an app library, occupying roughly 65% screen width and 80% height. Keep hints of the previous document/reference workspace dimmed behind it to convey continuity, but sharply prioritize the app library. Remove the decorative lower-right wallpaper slogan. NO menu bar, dock, taskbar, browser chrome or macOS traffic-light controls.

Main library panel has quiet mostly opaque graphite material, modest corners, exceptionally legible type and meticulous spacing. At top, a small completed request breadcrumb with subtle check symbol and exact text "Show my installed apps"; no waveform or active-listening indicator because listening has ended. Below a strong heading "Your apps", subtitle "12 installed". A clear dismiss X in upper right. Search input with magnifier, placeholder "Find an app or describe what you want to do", microphone icon at right. Under it a simple filter row: "All" selected, "Create", "Communicate", "Utilities"; a modest "A–Z" sort affordance at opposite end. These are panel-local controls, not a global menu bar.

Use a spacious orderly 4-column x 3-row grid of twelve app entries: recognizable carefully crafted icons with plain-text names and small readable purpose captions, placed directly on the library surface WITHOUT individual card containers. Entries exactly: "Browser" / "Explore the web"; "Calendar" / "Plan your time"; "Camera" / "Capture a moment"; "Files" / "Browse your documents"; "Mail" / "Stay in touch"; "Music" / "Listen and discover"; "Notes" / "Capture an idea"; "Photos" / "Your image library"; "Settings" / "Make it yours"; "Terminal" / "Work with commands"; "Text Editor" / "Write and edit"; "Videos" / "Watch and unwind". Icons polished and coherent, not macOS app icons. Browser tile visibly keyboard-focused with a subtle pale blue outline and a small ordinary mouse pointer hovering near it, other entries quiet. Do not invent extra apps outside these twelve. At panel bottom, a restrained thin divider and visible contextual action row "Browser" with a clear "Open" button, plus concise keyboard guidance "Arrow keys to browse · Enter to open · Esc to close". Include a small quiet prompt "You can also say “Open Browser”". This must read as a highly usable mouse/keyboard/voice app library within an intelligent OS, not a chat response listing software. Warm, welcoming and beautiful without neon, excessive glow, excessive transparency, oversized rounded cards or marketing decoration. High-resolution landscape image matching reference aspect ratio.
